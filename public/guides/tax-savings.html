01 · HOW IT WORKS

交税的基本盘，一分钟看懂

公民、PR，以及在新加坡工作或居住超过183天的外国人，按2025年收入在2026年3月1日至4月18日报税。

一条公式

收入 − 扣除（无上限）− 减免（封顶$80,000）= 应纳税收入 → 按累进税率算税 → 再减退税 = 实际要交的钱。

例：收入$200,000，用$20,000扣除+$80,000减免后只按$100,000计税，应缴税从$21,150降到$5,650，再减$200退税——省了七成多。

02 · 24 WAYS

24个省税方法，点卡片看详情

减免可叠加、总额封顶$80,000；扣除没有上限；退税在算完税后直接抵。带 ⭐ 的是主动型、省税空间最大的三项。

打工上班族

雇员CPF自动帮你减了。主动能做的是两件事：给自己和家人CPF充值最多减$16,000，再存SRS减$15,300——合计最多砍掉$31,300应税收入。年终花红高的，看看AW顶限。

职场妈妈

省税天花板最高的人群：WMCR（2024年前出生的娃按收入15–25%，2024年起出生固定$8,000–12,000）+ 子女减免$4,000 + 祖父母照顾$3,000，再叠PTR退税每娃最高$20,000。注意减免总额$80,000封顶。

自雇 / 小老板

业务开销全额扣除是基本盘，再加自雇CPF最高$37,740、自愿MediSave、SRS $15,300。记得留凭证，收入≤$200,000报表只要填两行。

外籍人士

没有CPF，但有专属组合：SRS每年$35,700（额度是本地人的2.3倍）+ 人寿保险最高$5,000 + 捐款250%扣除——三样都用上，高收入也能省出五位数。

房东

租金收入别忘了扣开销：15%简化扣除不用收据，房贷利息高的选实际开销更划算。空置期的合理开销也能扣。

去年忘了报的人

别慌，可以追溯补申4年：还没收到税单就重新提交，收到了就在30天内 Amend Tax Bill。多缴的税30天内退回。

只要有工作收入（打工、自雇、做生意）就自动享有：55岁以下$1,000、55–59岁$6,000、60岁以上$8,000；残障人士分别为$4,000 / $10,000 / $12,000。

IRAS自动计算，不用申报。

✔ 公民 · ✔ PR · ✔ 外国人

在经济上支持配偶、且对方年收入低于$8,000（或有残障）就能减。

已被你按配偶申报的人，别人就不能再把TA按父母或兄弟姐妹申报。

✔ 公民 · ✔ PR · ✔ 外国人

你自己缴的那部分强制CPF自动抵税。2025年的上限：普通工资月顶$7,400（2026年1月起升至$8,000）、全年工资顶$102,000、CPF年度限额$37,740。

和第13项的$8,000现金充值减免不冲突，可以都拿。

✔ 公民 · ✔ PR · ✔ 外国人

自由职业者自己缴CPF（尤其MediSave）也能减税，额度取三者最小：净收入的37%、$37,740、实际缴交额。

保存缴交证明，报税时要填实际金额。

✔ 公民 · ✔ PR · ✔ 外国人

每年有服役或参加NS活动的新加坡男性自动享有，金额依服役情况而定。

IRAS自动计算，不用申报。

仅 NSman

NSman的妻子可减$750。

不影响丈夫本人的NSman减免，夫妻都能享。

NSman 的配偶

服役者的父母每位可减$750。

双亲可分别申报。

NSman 的父母

赡养父母（同住或定期经济支持）：每位同住$9,000、不同住$5,500；残障父母$14,000 / $10,000。条件：父母年收入不超过$8,000（2025估税年起放宽到这个数）。

同一位父母只能由一个子女申报，兄弟姐妹先商量好。

✔ 公民 · ✔ PR · ✔ 外国人

职场妈妈专属：祖父母帮忙照顾16岁以下的孩子（或残障孩子），妈妈可减$3,000。

条件：祖父母自己不在工作。

职场妈妈

经济上支持残障兄弟姐妹，每位可减$5,500，照顾两位就是$11,000。

每位只能由一人申报；与父母减免不能对同一人重复申。

✔ 公民 · ✔ PR · ✔ 外国人

每个孩子$4,000（残障子女$7,500），亲生或领养都算。

建议由收入高的一方申报更省；与WMCR同报时系统自动分配最划算组合；残障可申请Disability Certification拿更高额度。

✔ 公民 · ✔ PR · ✔ 外国人

妈妈专属（爸爸不能申），按孩子出生时间分两种算法：2024年1月1日前出生的，按妈妈收入的15% / 20% / 25%（第1/2/3个起）；2024年起出生或领养的，改为固定额$8,000 / $10,000 / $12,000。两批孩子分别按各自制度算，可并存。例：妈妈年入$80,000，老大2022年生（15%=$12,000）+ 老二2024年生（固定$10,000）= 减$22,000。

孩子须是公民；与PTR退税可同享（先减WMCR再抵PTR）。收入高的妈妈，2024年前出生的娃按比例减更多。

公民孩子的妈妈

给自己的SA/MA/RA充值最多减$8,000，再帮家人（父母/配偶等）充值又减$8,000，存入当年立刻生效，和$37,740的CPF年度限额不冲突。

家人须是公民或PR且有CPF账户；给年收入超过$5,000的配偶充值不减税。充值入口见文末工具速查。

✔ 公民 · ✔ PR · ✘ 外国人

自愿多缴的MediSave同样抵税，IRAS从CPF系统自动获取记录。

年底才补缴也算当年；想多省一点可以考虑这项。

✔ 公民 · ✔ PR · ✘ 外国人

当年CPF缴交少于$5,000的人，可就自己的人寿保险保费（不含健康/意外/附加险）申报，额度=$5,000−已缴CPF。例：CPF只缴了$2,000，人寿保险最多可减$3,000。

没有CPF的外籍人士尤其适用。

✔ 公民 · ✔ PR · ✔ 外国人（CPF缴交<$5,000者）

往SRS账户存钱当年即减：公民/PR每年上限$15,300，外国人$35,700。账户内投资收益延税，到锁定的提取年龄后取出只按50%计税。提取年龄按首次存入时的法定退休年龄终身锁定——2026年7月1日起首次存入的锁定64岁。

打工族省税空间最大的一项，详见下方SRS专题。

✔ 公民 · ✔ PR · ✔ 外国人

房东二选一：简化方式按总租金15%直接扣、不用收据；或按实际开销申报——房贷利息、物业税、房屋保险、维修、中介费、广告费、空置期合理开销都算。

例：年租金$60,000，实际开销$11,000 > 简化$9,000，选实际更划算（收据留5年）。两者不能混用。

✔ 公民 · ✔ PR · ✔ 外国人

向政府认可的IPC慈善机构捐款享2.5倍扣除——捐$1,000等于从应税收入里减$2,500。现金、股票、房产、艺术品都可以。

捐款时要提供NRIC/FIN号码；当年用不完的额度可结转5年。

✔ 公民 · ✔ PR · ✔ 外国人

自雇、自由职业、个体户和合伙人：赚取收入的合理业务开销全额可扣——办公租金、设备折旧、专业费用、交通、客户应酬（不含私人部分）、专业协会会费等。

收入≤$200,000只需填两行报表（收入总额+开销总额）。

✔ 公民 · ✔ PR · ✔ 外国人

上班族自己掏钱、公司没报销的工作开销：居家办公的电费网费差额、客户应酬、专业协会会费、公共交通费（不含私家车）。

原则：完全用于工作、非私人用途、未被报销、不重复申报；账单收据留好备查。

✔ 公民 · ✔ PR · ✔ 外国人

政府财政好的年份主动给的"折扣"，不是每年都有，一旦有就人人自动享受。最近一次是2025估税年（SG60）：60%、封顶$200；2026估税年是否有，以当年财政预算公布为准。

例：应缴税$2,000，60%是$1,200但封顶$200，实际交$1,800。无需申请。

✔ 公民 · ✔ PR · ✔ 外国人

宝宝是新加坡公民就有：第1个孩子$5,000、第2个$10,000、第3个起每个$20,000——三个孩子合计$35,000退税额。

不是现金，存在IRAS账户里逐年自动抵税直到用完；父母可自由分配比例。

公民宝宝的父母

忘了父母减免、捐款没填？还没收到税单（NOA）的话，登录 myTax Portal → File Income Tax Return 重新提交完整版即可。

2021年及之后的税务年度有4年可补申：例如忘了2021年的父母减免，最迟2025年12月31日前都能申请。留好收据。

✔ 公民 · ✔ PR · ✔ 外国人

已经收到税单才发现填错？myTax Portal → Amend Tax Bill，填上要修改的项目，截止时间是收到税单后30天内。

改报时把所有资料一起更新，别只改一项；多缴的税IRAS会在30天内退回。

✔ 公民 · ✔ PR · ✔ 外国人

03 · SRS

一文读懂SRS，外国人也能用的省税利器

有存取条件的个人退休账户，公民、PR、外国人都能在 DBS / OCBC / UOB 任一银行开户。

经典案例：$400,000取10年，税$0

袁女士到了锁定的提取年龄时SRS有$400,000，每年取$40,000、应税只算$20,000——若没有其他收入，正好落在免税额内，10年应纳税额$0。

三个提醒（2026年7月起有变化）

① 提取年龄按你首次存入时的法定退休年龄终身锁定：2026年6月30日前存过第一笔的锁定63岁；2026年7月1日起首次存入的锁定64岁（法定退休年龄2030年前将升到65）——所以越早放进第一笔钱越好，哪怕只放$1。② 提前取款交5%罚金且全额计税（永久残疾/绝症、外国人满10年永久离境可豁免罚金、按50%计税）。③ 账户现金利息仅0.05%，存进去记得投资。
